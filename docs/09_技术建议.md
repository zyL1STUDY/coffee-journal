# 09 技术建议

## 前端

| 模块 | 建议 |
|---|---|
| 框架 | Flutter stable |
| 语言 | Dart |
| UI | Material 3 + 自定义 Design System |
| 架构 | Feature-first，保持简单模块化 |

## 状态管理

| 模块 | 建议 |
|---|---|
| 状态管理 | Riverpod |
| 原则 | UI 状态、表单状态、数据状态、错误状态分离 |

## 路由

| 模块 | 建议 |
|---|---|
| 路由 | GoRouter |
| 主路由 | Home / Journal / Profile |
| 弹层 | Record Flow、Coffee Memory 使用 Bottom Sheet 或等价页面状态 |

## 后端与数据库

| 模块 | 建议 |
|---|---|
| 后端 | MVP 第一版不依赖云端后端，本地优先 |
| 表 | `coffee_records` |
| 本地数据库 | Isar Database |
| 认证 | MVP 不需要用户登录，采用匿名模式 |
| 本地优先 | 所有数据默认存储在本地 |
| 云端数据库 | Supabase 作为未来同步方案，不影响 MVP 本地优先设计 |

## Local Database

| 模块 | 决策 |
|---|---|
| 数据库 | Isar Database |
| 使用范围 | Coffee Record、本地缓存、AI Message 保存结果 |
| 选择原因 | Flutter 生态成熟、查询性能优秀、支持对象存储、易于后续同步 Supabase、满足 MVP 所有需求 |

## Authentication

| 模块 | 决策 |
|---|---|
| MVP 登录 | 不需要用户登录 |
| 用户模式 | 匿名模式 |
| 数据位置 | 所有数据默认存储在本地 |
| 后续扩展 | 需要云同步时再增加登录功能 |
| 范围判断 | 登录属于 Future Feature，不属于 MVP |

## AI 接口

| 模块 | 建议 |
|---|---|
| Provider | OpenAI Responses API |
| 默认模型 | `gpt-5.5-mini` |
| 备用模型 | 如需更低成本，可切换为 `gpt-5.5-nano` |
| Prompt 管理 | 独立配置，不写死在 UI |
| 失败处理 | 返回默认文案或不展示 AI 区域 |
| 成本控制 | AI 只生成短句，避免长对话 |

## AI 使用原则

- AI 仅负责生成短文案。
- AI 不做聊天机器人。
- AI 不进行长文本生成。
- AI 不保存复杂上下文。
- Prompt 独立管理，不写死在 UI。

## AI Generation Strategy

| 场景 | 生成策略 | 失败处理 |
|---|---|---|
| Today Card | 每天首次打开 App 时生成一次；当天重复进入直接读取缓存 | 使用默认文案 |
| Journal Summary | 每个月首次进入 Journal 时生成一次；本月内不重复生成 | 使用默认文案 |
| Coffee Memory | 保存 Coffee Record 时生成一次；保存后写入数据库；后续打开永远读取保存结果，不重新请求 AI | 可为空或使用默认文案 |
| AI Failure | AI 失败不影响 Coffee Record 保存 | 记录失败状态，保留核心记录 |

## 图片存储

| 模块 | 建议 |
|---|---|
| 本地图片 | MVP 可本地缓存 |
| 云端图片 | Supabase Storage 或等价方案 |
| 抠图 / Sticker | MVP 可先使用普通照片缩略图；真正抠图后续实现 |

## Analytics

| 事件 | 说明 |
|---|---|
| record_start | 点击记录一杯 |
| photo_source_select | 选择拍照或相册 |
| record_cancel | 取消记录流程 |
| record_save | 保存咖啡 |
| photo_permission_denied | 拍照或相册权限被拒绝 |
| journal_open | 打开 Journal |
| memory_open | 打开 Coffee Memory |
| memory_edit | 编辑 Coffee Memory |
| memory_delete | 删除 Coffee Memory |
| profile_open | 打开 Profile |
| ai_error | AI 生成失败 |

## 环境变量

| 变量 | 用途 | 状态 |
|---|---|---|
| APP_ENV | 当前运行环境，例如 `development` / `production` | 已锁定 |
| DEBUG | 是否开启调试模式，例如 `true` / `false` | 已锁定 |
| AI_MODEL | AI 默认模型，例如 `gpt-5.5-mini` | 已锁定 |
| AI_API_KEY | AI 服务 key | 已锁定 |
| SUPABASE_URL | Supabase 项目地址，Future 云同步使用 | 预留 |
| SUPABASE_ANON_KEY | Supabase 客户端 key，Future 云同步使用 | 预留 |
| STORAGE_BUCKET | 图片存储 bucket，Future 云同步使用 | 预留 |

示例：

```env
APP_ENV=development
DEBUG=true
AI_MODEL=gpt-5.5-mini
```
