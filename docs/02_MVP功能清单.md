# 02 MVP 功能清单

## Must Have

| 功能名称 | 功能说明 | 用户价值 | 优先级 | 是否依赖其他功能 |
|---|---|---|---|---|
| Home / 今天 | 展示问候、日期、Today Card、记录入口、最近的咖啡。 | 快速进入记录，并获得当天轻量陪伴。 | P0 | 无 |
| 记录咖啡 | 从 Home 进入记录流程，支持拍照优先，也可跳过。 | 降低记录成本，先留下当下这一杯。 | P0 | Home |
| 照片来源 | 支持拍照或选择照片。 | 让咖啡记忆更有画面感。 | P0 | 记录咖啡 |
| 来源分支记录 | 支持连锁品牌、独立咖啡店、自己做三类路径。 | 匹配真实喝咖啡场景。 | P0 | 记录咖啡 |
| Journal | 以月历回顾咖啡记录，照片日期显示缩略图，多杯显示 Badge。 | 一眼看到这个月的咖啡记忆。 | P0 | Coffee Record |
| Coffee Memory | 用 Bottom Sheet 展示单条咖啡记忆。 | 回看某一杯咖啡的照片、AI Message 和我的记录。 | P0 | Journal |
| Profile / 我的 | 展示个人入口与 Coming Soon 项。 | 承载账户、偏好、关于等入口。 | P0 | 无 |

## Should Have

| 功能名称 | 功能说明 | 用户价值 | 优先级 | 是否依赖其他功能 |
|---|---|---|---|---|
| AI Summary | Journal 下方展示一句轻量总结。 | 提供观察感，不打扰主流程。 | P1 | Coffee Record |
| 保存时 AI Message | 记录保存时生成并保存一句 AI 文案，在 Coffee Memory 中展示。 | 让每杯咖啡带有记忆温度。 | P1 | 记录咖啡 |
| Statistics | 展示本月咖啡、去过店铺、连续记录等轻量统计。 | 提供回顾信息，不喧宾夺主。 | P1 | Coffee Record |
