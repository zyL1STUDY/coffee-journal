# 04 页面说明

## 01 Home / 今天

| 项目 | 内容 |
|---|---|
| 页面目的 | 提供当天入口和记录咖啡的主入口。 |
| 进入来源 | App 启动默认进入；底部导航点击「今天」进入；保存记录后返回并刷新。 |
| 展示内容 | `早安`、日期、Today Card、`+ 记录一杯`、`最近的咖啡`、底部导航。 |
| 主要操作 | 点击 `+ 记录一杯` 进入 `02 Record Flow`。 |
| 次要操作 | 点击底部导航进入 `07 Journal` / `09 Profile`。 |
| 退出去向 | Record Flow、Journal、Profile。 |
| Empty State | 今日无记录时，Today Card 显示默认一句话；最近的咖啡列表可为空或显示轻量占位文案。 |
| Loading State | 首次读取本地记录时可显示轻量占位，不阻塞页面。 |
| Error State | 本地数据读取失败时显示默认首页内容，并提示稍后重试。 |

## 02 Record Flow

| 项目 | 内容 |
|---|---|
| 页面目的 | 引导用户开始记录这一杯。 |
| 进入来源 | Home 点击 `+ 记录一杯`。 |
| 展示内容 | 拍照优先入口、直接记录入口。 |
| 主要操作 | 点击 `拍一张吧` 进入 `03 Photo Source`。 |
| 次要操作 | 点击 `直接记录` 进入记录详情分支，默认可进入 `05 Cafe Record` 或来源选择逻辑。 |
| 退出去向 | Photo Source、Brand Record、Cafe Record、Homemade Record、Home。 |
| 按钮跳转 | `拍一张吧` → Photo Source；`直接记录` → 记录详情分支。 |
| Empty State | 不适用。 |
| Loading State | 不适用。 |
| Error State | 不适用。 |

## 03 Photo Source

| 项目 | 内容 |
|---|---|
| 页面目的 | 选择照片来源。 |
| 进入来源 | Record Flow 点击 `拍一张吧`。 |
| 展示内容 | 拍照、选择照片。 |
| 主要操作 | 拍照或选择照片。 |
| 次要操作 | 返回 Record Flow。 |
| 退出去向 | 成功选择照片后进入记录详情分支。 |
| 按钮跳转 | `拍一张吧` / `选一张吧` → 记录详情分支。 |
| Empty State | 不适用。 |
| Loading State | 打开相机或相册时使用系统加载状态。 |
| Error State | 相机权限、相册权限、图片失败时显示错误提示，并允许返回或跳过照片。 |

## 04 Brand Record

| 项目 | 内容 |
|---|---|
| 页面目的 | 记录连锁品牌咖啡。 |
| 进入来源 | Record Flow 或 Photo Source 后选择连锁品牌路径。 |
| 展示内容 | 品牌选择、可选饮品名、照片、备注、保存按钮。 |
| 主要操作 | 点击 `保存这一杯`。 |
| 次要操作 | 返回上一步。 |
| 退出去向 | 保存成功后返回 Home 并刷新数据。 |
| 按钮跳转 | 保存成功 → Home Refresh。 |
| 保存成功反馈 | 保存 Coffee Record；AI 失败也不阻塞保存；返回 Home 后最近咖啡更新。 |
| Empty State | 品牌未选择时保存按钮可禁用或提示选择来源。 |
| Loading State | 保存中按钮进入加载态。 |
| Error State | 保存失败时停留当前 Bottom Sheet，显示错误提示。 |

## 07 Journal

| 项目 | 内容 |
|---|---|
| 页面目的 | 浏览和回顾咖啡记忆，不承担新增记录入口。 |
| 进入来源 | 底部导航点击 Journal；保存记录后用户也可从 Home 切换进入。 |
| 展示内容 | 月份、月份箭头、完整月历、横向统计、AI Summary、底部导航。 |
| 日期规则 | 无记录只显示日期；有记录显示日期 + 圆形照片缩略图；多杯显示 Badge。 |
| 主要操作 | 点击照片缩略图打开 `08 Coffee Memory`。 |
| 次要操作 | 切换月份、底部导航切换页面。 |
| 退出去向 | Coffee Memory、Home、Profile。 |
| 按钮跳转 | 日期照片缩略图 → Coffee Memory；月份箭头 → 切换月份。 |
| Empty State | 无 Coffee Record 时显示空月历；统计为 0；AI Summary 使用默认文案或隐藏。 |
| Loading State | 加载记录时可显示月历 Skeleton 或轻量占位。 |
| Error State | 数据读取失败时保留月历结构，显示重试提示。 |

## 08 Coffee Memory

| 项目 | 内容 |
|---|---|
| 页面目的 | 展示一条咖啡回忆，不是后台详情页。 |
| 进入来源 | Journal 点击有记录日期的照片缩略图。 |
| 展示内容 | Sticker 咖啡图片、保存时 AI Message、饮品名称、来源、时间、我的记录、编辑、删除。 |
| 信息层级 | Sticker 图片 → AI Message → 饮品名称 → 来源 → 时间 → 我的记录 → 编辑 / 删除。 |
| 主要操作 | 编辑。 |
| 次要操作 | 删除、点击背景关闭。 |
| 退出去向 | 关闭后返回 Journal；编辑完成后返回 Coffee Memory 并刷新内容；删除后返回 Journal 并刷新数据。 |
| 按钮跳转 | `编辑` → 编辑当前 Coffee Record；`删除` → 二次确认；确认删除 → Journal。 |
| 删除确认 | 删除前必须二次确认；确认后软删除 Coffee Record，不直接物理删除。 |
| 保存成功反馈 | 编辑保存成功后回到 Coffee Memory，内容刷新。 |
| Empty State | 不适用；无有效记录时不应打开该页。 |
| Loading State | 打开详情或编辑保存时显示轻量加载态。 |
| Error State | 记录不存在或已删除时关闭 Bottom Sheet，并在 Journal 提示记录不可用。 |

## 09 Profile / 我的

| 项目 | 内容 |
|---|---|
| 页面目的 | 承载个人与设置类入口。 |
| 进入来源 | 底部导航点击「我的」。 |
| 展示内容 | 个人资料、语言设置、数据与隐私、关于 Coffee Journal、Sticker 收藏 Coming Soon、桌面小组件 Coming Soon。 |
| 主要操作 | 点击可用列表入口。 |
| 次要操作 | 底部导航切换页面。 |
| 退出去向 | Home、Journal；设置类子页面暂不进入 MVP。 |
| 按钮跳转 | Coming Soon 功能不可进入正式功能；点击后显示 Toast 或不响应。 |
| Empty State | 未登录或无资料时显示默认头像和默认名称。 |
| Loading State | 读取本地设置时可显示轻量占位。 |
| Error State | 设置读取失败时保留默认值。 |
