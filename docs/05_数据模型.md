# 05 数据模型

## 设计原则

- MVP 优先使用一个核心数据对象：`Coffee Record`。
- `Statistics` 不建议在 MVP 阶段单独建表，优先由 `Coffee Record` 实时计算。
- `AI Message` 不建议在 MVP 阶段单独建表，先保存在 `Coffee Record` 中。
- 删除使用软删除，不直接物理删除。

## Coffee Record

| 字段名称 | 数据类型 | 是否必填 | 默认值 | 字段说明 | 关联关系 |
|---|---|---:|---|---|---|
| id | string / uuid | 是 | 自动生成 | 记录唯一 ID | User |
| created_at | datetime | 是 | 当前时间 | 记录创建时间，用于 Journal 展示和排序 | Journal / Home |
| updated_at | datetime | 是 | 当前时间 | 最近更新时间，编辑记录时更新 | Coffee Memory |
| is_deleted | bool | 是 | false | 是否软删除 | Coffee Memory |
| deleted_at | datetime | 否 | null | 软删除时间 | Coffee Memory |
| source_type | enum | 是 | 无 | `brand` / `cafe` / `homemade` 之一 | Record Flow |
| source_name | string | 是 | 无 | 根据 `source_type` 表示品牌名、咖啡店名或制作方式 | Record Flow / Coffee Memory |
| drink_name | string | 否 | null | 用户记得的真实饮品名，例如红酒美式、生椰拿铁 | Coffee Memory |
| photo_url | string | 否 | null | 咖啡照片地址；用户可跳过拍照 | Journal / Coffee Memory |
| note | string | 否 | null | 我的记录 | Coffee Memory |
| ai_message | string | 否 | null | 保存时生成并固定保存的一句话 AI Message | Coffee Memory |
| ai_status | enum | 是 | `not_requested` | `not_requested` / `success` / `failed` | AI |
| ai_created_at | datetime | 否 | null | AI Message 生成时间 | AI |

## User

| 字段名称 | 数据类型 | 是否必填 | 默认值 | 字段说明 | 关联关系 |
|---|---|---:|---|---|---|
| id | string / uuid | 是 | 自动生成 | 用户 ID；MVP 如果不登录，可使用本地匿名 ID | Coffee Record |
| display_name | string | 否 | null | 显示名称 | Profile |
| avatar_url | string | 否 | null | 头像 | Profile |
| created_at | datetime | 是 | 当前时间 | 用户创建时间 | Settings |

## Statistics（Future）

MVP 不建议单独建立 `Statistics` 表。

统计数据优先从未删除的 `Coffee Record` 实时计算：

| 统计项 | 计算依据 | 使用页面 |
|---|---|---|
| coffee_count | 当前月份 `Coffee Record` 数量 | Journal |
| shop_count | 当前月份 `source_type=cafe` 或有店铺来源的去重数量 | Journal |
| streak_days | 按 `created_at` 计算连续记录天数 | Journal |

## AI Message（Future）

MVP 不建议单独建立 `AI Message` 表。

先将以下字段保存在 `Coffee Record` 中：

- `ai_message`
- `ai_status`
- `ai_created_at`

未来如果需要多轮 AI、历史 Prompt 追踪或多条 AI 结果，再拆分独立 AI Message 表。

## Settings

| 字段名称 | 数据类型 | 是否必填 | 默认值 | 字段说明 | 关联关系 |
|---|---|---:|---|---|---|
| user_id | string | 是 | 无 | 用户 ID | User |
| language | string | 否 | `zh-CN` | 显示语言 | App |
| notifications_enabled | bool | 否 | false | 通知开关，MVP 可不实现 | Future |
