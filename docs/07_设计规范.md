## 页面规范

- 移动端优先。
- 默认 iPhone 尺寸：390 x 844。
- 当前 MVP 不设计桌面布局。
- 页面应温暖、安静、克制，不做 Landing Page 风格。
- Journal 的主角是月历。
- Coffee Memory 的主角是这杯咖啡和这条记忆。
