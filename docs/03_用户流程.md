# 03 用户流程

## 主流程

```mermaid
flowchart TD
  A["Home / 今天"] --> B["Record Flow / 记录流程"]
  B --> C["Photo Source / 照片来源（可选）"]
  C --> D{"选择来源"}
  D --> E["Brand Record / 连锁品牌"]
  D --> F["Cafe Record / 独立咖啡店"]
  D --> G["Homemade Record / 自己做"]
  E --> H["Save / 保存"]
  F --> H
  G --> H
  H --> I["Home Refresh / 首页刷新"]
  I --> J["Journal / 咖啡记忆月历"]
  J --> K["Coffee Memory / 咖啡记忆详情"]
  I --> L["Profile / 我的"]
```
