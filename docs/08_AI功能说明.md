# 08 AI 功能说明

## AI 定位

AI 是观察者，不是聊天机器人、心理咨询或每日语录。

AI 应该：

- 轻陪伴
- 轻观察
- 轻提醒

## AI 不做

- 不做聊天机器人。
- 不做心理咨询。
- 不做健康诊断。
- 不评价用户。
- 不制造焦虑。
- 不建议咖啡摄入量。
- 不输出心灵鸡汤。

## AI 功能清单

| AI 功能 | Prompt Version | 功能目的 | 触发条件 | 输入内容 | 输出内容 | Fallback | Loading | 错误处理 |
|---|---|---|---|---|---|---|---|---|
| Today Card 一句话 | Today Card Prompt v1 | 让首页更自然，不制造任务感。 | 打开 Home。 | 日期、最近记录、今日记录状态；天气为 Future。 | 一句自然文案，例如“今天有点冷，热拿铁应该很舒服”。 | 使用默认文案。 | 不阻塞 Home 展示。 | 失败时记录错误，不影响页面使用。 |
| Journal AI Summary | Journal Summary Prompt v1 | 对本月记录做轻量观察。 | 打开 Journal 或记录变化后刷新。 | 本月 Coffee Record、来源、频率、日期分布。 | 一句总结，例如“最近开始更喜欢独立咖啡店了。” | 使用默认文案或隐藏该区域。 | 不阻塞月历展示。 | 失败时记录错误，保留 Journal。 |
| Coffee Memory AI Message | Coffee Memory Message Prompt v1 | 保存某杯咖啡时留下固定 AI Message。 | 保存 Coffee Record 时。 | 当前记录内容、source_type、source_name、drink_name、note、photo_url 是否存在。 | 一到两行 AI Message，例如“今天有点冷，这杯热拿铁刚刚好。” | 可保存空值或默认短句。 | 保存按钮可显示保存中。 | AI 失败不影响 Coffee Record 保存。 |

## Prompt Version 管理

| Prompt | 当前版本 | 说明 |
|---|---|---|
| Today Card Prompt | v1 | 首页一句话。 |
| Journal Summary Prompt | v1 | Journal 月度轻量观察。 |
| Coffee Memory Message Prompt | v1 | 保存记录时生成并固定保存。 |

Prompt 文案应独立管理，不直接散落在 UI 组件中。后续如果调整语气或输入字段，需要升级版本并记录变更原因。

## AI 失败规则

- AI 失败不影响保存 Coffee Record。
- Coffee Memory 的 AI Message 是保存时生成并固定保存，不是每次打开实时生成。
- Today Card 和 Journal Summary 可以使用默认文案兜底。
- AI 失败时不向用户输出技术错误细节。
- AI 结果最多一到两行，不能抢占页面主要信息。
