# 01 项目概览

## 产品愿景

Coffee Journal 是一款 AI Coffee Journal。它通过记录每一杯咖啡，帮助用户留下日常生活里的轻量记忆。

核心理念：

> More than coffee. More than memories.

## 产品定位

| 项目 | 内容 |
|---|---|
| 产品名称 | Coffee Journal |
| 产品类型 | AI 咖啡日记 |
| 平台 | 移动端 App |
| MVP 版本 | MVP v1.0 |
| 设计语言 | Minimal / Warm / Calm / Cute (Subtle) |

## 产品目标

- 让记录咖啡像留下一个生活片段，而不是完成任务。
- 通过 Journal 月历让用户回看这个月喝过哪些咖啡。
- 用轻量 AI 一句话提供观察和陪伴，不做聊天机器人。

## 用户痛点

- 普通记录工具过于表格化，记录成本高。
- 单纯统计咖啡缺少情绪和生活记忆。
- 用户希望快速留下当下这一杯，而不是先填写复杂字段。
- 有些用户不喜欢拍照，或当下不方便拍照；记录流程需要支持跳过拍照，避免让“拍照”变成记录门槛。

## 目标用户

- 有日常喝咖啡习惯的人。
- 喜欢记录生活片段，但不想写长日记的人。
- 喜欢温暖、轻量、个人化 App 体验的用户。

## MVP 范围

- Home / 今天
- Record Flow / 记录流程
- Photo Source / 照片来源
- Brand Record / 连锁品牌记录
- Cafe Record / 独立咖啡店记录
- Homemade Record / 自己做记录
- Journal / 咖啡记忆月历
- Coffee Memory / 咖啡记忆详情
- Profile / 我的
- 轻量 AI Summary / AI Message
